Key Equations
Boundary: Vds = Vgs − Vth  →  Vgs = Vth + Vds
Saturation (Vgs ≤ Vth + Vds): Id = ½·k·(Vgs−Vth)²
Triode (Vgs > Vth + Vds): Id = k·[(Vgs−Vth)·Vds − Vds²/2]
Note: On this transfer curve (Ids vs Vgs at fixed Vds), the device enters triode once Vgs > Vth + Vds.
