Quick Reference

N-CH Enhancement MOSFET
Cutoff
Vgs < Vth
Id = 0
Triode / Linear
Vds < Vgs−Vth
Id = k·[(Vov·Vds − Vds²/2)]
Saturation
Vds ≥ Vgs−Vth
Id = ½·k·(Vov)²
Key relations
Vov = Vgs − Vth
gm = 2Id / Vov
